- **Filesystem inbox protocol preserved:** All agent communication still works via `~/.loom/inbox/<project>/`.

## Task 1: Sub-50ms `hybrid_query` & Offline-Safe Embeddings

**Why:**
1. `EmbeddingGenerator` (`daemon/embeddings.py`) loads `SentenceTransformer(self.model_name)` per instance. Both `GraphEngine.hybrid_query` (`daemon/graph_engine.py:326`) and `EmbeddingStore.search` (`daemon/embeddings.py:106`) instantiate a fresh `EmbeddingGenerator()` on every call, reloading the PyTorch model (~1.8s) every query.
2. When offline or in a network-restricted sandbox, `SentenceTransformer("all-MiniLM-L6-v2")` attempts a network `HEAD` request to `huggingface.co`, retries 5 times (5s stall), and fails into zero-vector degraded mode even when the weights are already cached on disk.
3. `GraphEngine.hybrid_query` re-embeds all `N` graph node IDs (`gen.embed_batch([str(k) for k in node_keys])`) on every single query (~3.6s for 2,469 nodes) instead of caching node vectors keyed by `(str(graph_path), mtime)` alongside `_graph_cache`.

**Files:**
- Modify: `daemon/embeddings.py`
- Modify: `daemon/graph_engine.py`
- Test: `tests/test_embeddings.py`, `tests/test_graph_engine.py`
- Regenerate: `benchmarks/loom.json`, `BENCHMARKS.md`

```python
@pytest.mark.asyncio
async def test_initial_build_blocks_concurrent_finding_update():
    """While request_initial_build is in flight, a finding request_update coalesces into dirty."""
    started = asyncio.Event()
    release = asyncio.Event()
    calls = []

    class SlowGraph:
        available = True
        async def build_project(self, path):
            calls.append(("build", path))
            started.set()
            await release.wait()
            return BuildResult(project="p", status="completed", nodes=10, edges=20, duration_s=1.0)

    updated = []
    async def on_updated(proj, path, res):
        updated.append((proj, res.nodes))

    coord = GraphUpdateCoordinator(SlowGraph(), on_updated, min_interval_s=0.01)
    coord.request_initial_build("p", "/repo")
    await started.wait()

    # Finding arrives while initial build is running -> must NOT launch 2nd build right now
    await coord.request_update("p", "/repo")
    assert len(calls) == 1

    release.set()
    await asyncio.sleep(0.05)
    assert len(calls) == 2  # trailing rebuild ran after initial build completed
```

Create `daemon/federation.py` (~130 LOC):
- `FederatedIndex`:
  - Uses `GraphEngine._read_graph_json` (mtime-cached, read-only) so it never mutates any project's `graph.json`.
  - `async def build_index(self, projects: list[dict]) -> dict`: indexes nodes and adjacency lists per `project_id`, returning `{"projects_indexed": int, "total_nodes": int, "total_edges": int, "shared_symbols": int}`.

  - `async def shared_symbols(self, min_projects: int = 2, limit: int = 50) -> list[dict]`: returns symbols (`label` / function / class names) that appear across `>= min_projects` repositories, sorted by project count and total degree.
  - `async def query(self, question: str, depth: int = 2, top_k: int = 10) -> list[dict]`: combines keyword/symbol score + `GraphEngine.hybrid_query` across indexed projects and tags each result with `"project": project_id`.
